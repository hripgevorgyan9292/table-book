# TableBook

Սեղանների ամրագրման համակարգ Հայաստանի ռեստորանների և սրճարանների համար։
Հյուրն ընտրում է ռեստորանը, օրը, ժամը և սեղանը սրահի հատակագծի վրա, կարող է նախապես պատվիրել ուտեստներ և վճարել կանխավճարը, իսկ ադմինը հաստատում կամ մերժում է ամրագրումը։

## Հնարավորություններ

### Հյուրերի համար (`index.html`)
- **Ռեստորաններ.** Հայաստանի 24 քաղաքների ռեստորաններ։ Գլխավոր էջում երևում են պատահական 9-ը, որոնք թարմանում են ամեն 10 րոպեն մեկ։
- **Ամրագրում հատակագծով.** սրահի սխեմա՝ պատերով, պատուհաններով, բարով և 8 սեղանով։ Ամեն ամրագրում **1 ժամ** է։
- **Ճաշացանկ.** ամրագրման հետ կարելի է նախապես պատվիրել ուտեստներ։
- **Կանխավճար.** 5000 դրամ, վճարվում է 15 րոպեի ընթացքում (`pay.html`)։ Մնացածը վճարվում է ռեստորանում։
- **Իմ ամրագրումները.** ստատուսով (սպասում է / հաստատված / չեղարկված) և մերժման պատճառով, եթե ադմինը մերժել է։
- **Չեղարկում** ամրագրումից առնվազն 1 ժամ առաջ։
- **Ծանուցումներ**, որոնք ջնջվում են 48 ժամ անց։
- **Երեք լեզու** (անգլերեն, հայերեն, ռուսերեն) և **բաց/մուգ ռեժիմ**։

### Ադմինի համար (`admin.html`)
- **Ամրագրումներ**՝ ըստ քաղաքների. **հաստատել** կամ **մերժել** հաղորդագրությամբ։
- **Ազատ և զբաղված սեղաններ** ըստ ռեստորանի և օրվա։
- **Ռեստորաններ.** ավելացնել, փոխել, ջնջել, որոնել, **ներմուծել կայքի հղումից**։
- **Ճաշացանկ.** ուտեստներ ավելացնել, փոխել, ջնջել։

## Ինչպես գործարկել

1. Տեղադրեք [Node.js](https://nodejs.org)-ը, **22.13 կամ ավելի նոր** տարբերակ (LTS)։
2. `table-book` թղթապանակում բացեք տերմինալ և գործարկեք.
   ```bash
   npm start
   ```
3. Բրաուզերում բացեք **http://localhost:3000**։

Առաջին գործարկման ժամանակ սերվերը ինքն է ստեղծում տվյալների բազան (`data/tablebook.db`) և Երևանի 10 ռեստորանը։

## Լրացուցիչ տվյալներ (seeders)

Գործարկեք սերվերը գոնե մեկ անգամ, ապա.

| Հրաման | Ինչ է անում |
|---|---|
| `npm run seed` | Ստեղծում է ադմինին՝ **Super Admin** (`admin@tablebook.local`)։ Գաղտնաբառը ցույց է տրվում **միայն մեկ անգամ** |
| `npm run seed -- --reset` | Տալիս է Super Admin-ին նոր գաղտնաբառ (եթե հինը կորել է) |
| `npm run seed:restaurants` | Ավելացնում է 5 ռեստորան Երևանից բացի ամեն քաղաքում |
| `npm run seed:menus` | Տալիս է ճաշացանկ այն ռեստորաններին, որոնք դեռ չունեն |
| `npm run seed:dish-photos` | Ավելացնում է լուսանկարներ առանց նկարի ուտեստներին |
| `npm run make-admin -- email@mail.com` | Դարձնում է գրանցված օգտատիրոջն ադմին |

Բոլոր seeder-ները կարելի է կրկին գործարկել. արդեն ավելացվածը նորից չեն ավելացնում։

## Ադմինի մուտք

- Գլխավոր էջում սեղմեք **«Admin»**, կամ բացեք **http://localhost:3000/admin.html**։
- Մուտք գործեք Super Admin-ի email-ով և գաղտնաբառով։
- Ադմինի էջը **հյուրերի հաշիվներ չի ընդունում**։

## Փորձնական վճարում

Վճարումը **փորձնական է**. իրական գումար չի գանձվում, և այն աշխատում է միայն `localhost`-ով։
- Ցանկացած ճիշտ համար (Luhn ստուգումով), օրինակ՝ `4242 4242 4242 4242`, **ընդունվում է**։
- `4000 0000 0000 0002`-ը **մերժվում է**. սա մերժման ստուգման համար է։

Գումարը «պահվում» է քարտի վրա և գանձվում է միայն այն ժամանակ, երբ ադմինը հաստատում է ամրագրումը։ Մերժման կամ չեղարկման դեպքում վերադարձվում է։

## Ֆայլերի կառուցվածք

| Ֆայլ | Ինչ է |
|---|---|
| `server.js` | Սերվերը. API, տվյալների բազա (SQLite), մուտք (JWT) |
| `index.html`, `script.js` | Գլխավոր էջը՝ հյուրերի համար |
| `admin.html`, `admin.js` | Ադմին պանելը |
| `pay.html`, `pay.js` | Կանխավճարի փորձնական վճարման էջը |
| `style.css` | Բոլոր էջերի ոճը (բաց և մուգ ռեժիմ) |
| `i18n.js` | Բոլոր տեքստերը երեք լեզվով |
| `seeders/` | Լրացուցիչ տվյալներ ավելացնող հրամաններ |
| `make-admin.js` | Օգտատիրոջն ադմին դարձնող հրաման |
| `data/` | Տվյալների բազան և մուտքի բանալին (**GitHub չի ուղարկվում**) |

## Կարևոր է իմանալ

- **GitHub Pages**-ում (`hripgevorgyan9292.github.io/table-book`) երևում է միայն էջի տեսքը։ Pages-ը չի կարող գործարկել `server.js`-ը, ուստի ռեստորանները, մուտքը, ամրագրումը և ադմին պանելը այնտեղ չեն աշխատում։ Ամբողջությամբ կայքն աշխատում է `npm start`-ով կամ Node.js աջակցող հոսթինգում (օրինակ՝ Render, Railway)։
- `server.js`-ը փոխելուց հետո սերվերը պետք է **վերագործարկել** (Ctrl+C, ապա `npm start`)։ Էջերի ֆայլերը փոխելուց հետո բավական է թարմացնել էջը (Ctrl+F5)։
- Ռեստորանների և ուտեստների լուսանկարները [Unsplash](https://unsplash.com)-ից են։
